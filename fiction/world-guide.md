# RUIN 세계관 안내 / Reader’s World Guide

> **스포일러 범위:** 작품 소개와 1화 초반에 공개되는 정보만 담았습니다.
> 인물의 생사, 사건의 진상, 이후 시즌의 주요 전개는 설명하지 않습니다.

## 30초 소개

인류는 태양계 밖까지 문명을 넓혔지만, 빛보다 빠르게 소식을 주고받지는 못합니다.
멀리 떨어진 정착지는 같은 기술을 쓰면서도 서로 다른 법과 생활방식을 만들었고,
지구의 명령은 때로 몇 년, 몇십 년 뒤에야 도착합니다.

이 세계에서 문명을 움직이는 것은 영웅 한 명이 아니라 전력망, 산소 배급표,
통신 정족수, 고장 난 부품을 갈아 끼우는 노동입니다. 시스템은 정해진 규칙을
정확하게 지킵니다. 문제는 그 규칙이 **누구를 사람으로 세는가**입니다.

## 이야기가 시작되는 곳

### 지구권

태양계 문명의 행정과 검증이 모이는 중심입니다. 마라 보스는 이곳에서 문명
생존 시뮬레이션의 결과를 검사합니다. 보고서에는 전쟁·기아·범죄 사망자 0명,
문명 존속 확률 99.97%라고 적혀 있습니다.

### 외곽 정착지

지구의 전력과 통신망에 의존하지만, 장애가 생기면 현장 사람들이 먼저 대가를
치르는 생활권입니다. 정착지의 하루는 거대한 우주선과 비슷합니다. 전력이
끊기면 조명보다 먼저 산소, 냉각, 항법, 병원의 남은 시간이 계산됩니다.

### 다른 항성계

이주선과 자동 건설 장비를 먼저 보내 세운 먼 문명권입니다. 지구와 같은 기술적
뿌리에서 출발했어도, 긴 통신 지연 속에서 독자적인 제도와 이해관계를 갖게
됐습니다. 작품은 어느 한쪽을 선하거나 악한 국가로 정해두지 않습니다.

## 처음 등장하는 시스템

- **RUIN** — 여러 문명 기반 시설과 장기 생존 결과를 검증하는 체계입니다. 결과를
  보여주지만, 무엇을 옳다고 볼지는 대신 결정해주지 않습니다.
- **HELIOS** — 태양 가까이의 수집기 10,000기로 전력을 모아 보내는 분산 전력망입니다.
  수신지를 인증할 수 없으면 빔을 0 MW로 내리는 것이 가장 중요한 안전 규칙입니다.
- **FIRST LIGHT** — 통신 단절과 연쇄 고장을 재현하는 검증 시나리오입니다. 같은
  조건에서는 같은 결과가 나와야 합니다.
- **AGRARIA** — 식량, 물, 산소 순환을 담당하는 생존 기반 시설입니다.
- **DATACORE** — 항법과 문명 운영 계산을 맡습니다. 전력과 냉각이 부족할 때 다른
  생존 설비와 같은 자원을 놓고 경쟁합니다.
- **MNEMOSYNE** — 죽은 사람의 기억, 목소리, 신경 기록을 보존합니다. 기록이 사람인지,
  사람의 흔적인지는 아직 합의되지 않았습니다.
- **MENDER** — 사람이 바로 갈 수 없는 곳에서 기반 시설을 고치는 자율 정비 장비입니다.

## 숫자로 보는 1화

| 숫자 | 뜻 |
|---:|---|
| 99.97% | 공식 보고서가 제시한 문명 존속 확률 |
| 0명 | 보고서에 기록된 전쟁·기아·범죄 사망자 |
| 18,421,903명 | 생존 계산에서 빠진 ‘인과적으로 검증되지 않은 인구’ |
| 0.51 | 한 인구를 문명의 구성원으로 인정하는 통신·신원 정족수 |
| 10,000기 | HELIOS를 이루는 태양 에너지 수집기 수 |
| 0 MW | 인증을 잃은 수집기가 지켜야 하는 안전 출력 |

숫자는 분위기를 내기 위한 장식이 아닙니다. 누군가에게 남은 산소가 몇 분인지,
표결에서 몇 표가 부족했는지, 장부에서 몇 명이 빠졌는지가 다음 사건의 원인이
됩니다.

## 이 세계의 기본 규칙

1. **빛보다 빠른 통신은 없다.** 멀리 있는 사람들은 같은 순간을 공유하지 못합니다.
2. **열과 전력은 공짜가 아니다.** 계산, 생명 유지, 무기, 기억 보존은 같은 자원을 씁니다.
3. **안전 규칙에는 이유가 있다.** 한 번 사람을 살린 규칙이 다음에는 다른 사람을 죽일 수 있습니다.
4. **기록의 0은 현실의 0이 아니다.** 장부에 없는 사람은 통계 안에서 죽지 않습니다.
5. **모든 입장은 누군가를 지킨 적이 있다.** 그래서 선택은 선악보다 책임의 문제가 됩니다.

## 무엇을 읽는 이야기인가

RUIN은 멸망을 막는 초인보다, 멸망을 미루기 위해 명단과 밸브와 투표지를 만지는
사람들의 이야기입니다. 인간은 서로를 살릴 수 있다는 믿음과, 인간은 기회만
주어지면 서로를 해친다는 믿음이 같은 사건을 겪으며 자리를 바꿉니다.

사람들은 서로 사랑하고, 배신하고, 때로는 타인을 위해 자기 몫을 내놓습니다.
각자의 작은 철학은 실제로 누군가를 살리고, 동시에 이름을 가진 다른 누군가에게
값을 치르게 합니다.
