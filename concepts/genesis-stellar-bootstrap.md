# GENESIS — stellar civilization bootstrap

GENESIS is RUIN's first cross-module campaign. A seed spacecraft arrives with PROMETHEUS reactors and CORVUS scouts, establishes certified ore through FOUNDRY, grows factories through PROGENITOR, replaces bootstrap fission with HELIOS collectors, then commissions AGRARIA and GRAVITAS habitation. Self-sufficiency is evidence-gated rather than declared by elapsed time.

The deterministic annual model tracks factories, collectors, electrical power, certified stock, population, and five milestones. Ore poverty, metrology drift, reactor trip, and pathogen scenarios reveal which dependency prevents closure. Growth equations are deliberately fictional scenario parameters; this is not a colonization forecast, population model, or mission plan.

The next GENESIS layer should use each module's real snapshot rather than aggregate proxies, introduce finite imported precision stock, model shipment light-time, and emit a signed campaign ledger that SENTINEL can replay.
